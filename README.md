# 📊 Retail Sales Analytics Dashboard | Power BI

## 📌 Project Overview

This project is an interactive **Retail Sales Analytics Dashboard** developed using **Microsoft Power BI**.

The dashboard provides insights into sales performance, profitability, regional performance, product performance, customer metrics, and order status. It helps businesses understand their sales trends and identify areas of growth and improvement.

---

## 🎯 Project Objectives

- Analyze overall sales and profit performance
- Identify the best-performing regions
- Analyze top-selling products
- Compare profit across different categories
- Track monthly sales performance
- Analyze order status
- Monitor key business KPIs
- Create an interactive and user-friendly dashboard

---

## 📈 Dashboard Features

### 🔹 Sales by Region
Analyzes sales performance across different regions such as:

- West
- East
- South
- North

### 🔹 Top 10 Products
Identifies the top-performing products based on sales.

### 🔹 Profit by Category
Analyzes profitability across different product categories.

### 🔹 Monthly Sales Analysis
Compares monthly sales performance and identifies trends.

### 🔹 Order Status
Provides an overview of order statuses such as:

- Delivered
- Shipped
- Pending
- Cancelled

### 🔹 Interactive Filters

Users can dynamically filter the dashboard using:

- Year
- Region
- Category
- Brand
